# Planned scope — not implemented

The following modules are intentionally visible as future work so the portfolio remains truthful:

1. **Intercompany graph and eliminations** — reciprocal balance matching, counterparty evidence,
   elimination proposals, and human approval.
2. **Integration mapping and sync simulator** — connector contracts, incremental cursors,
   retries, reconciliation, replay, and observable failure recovery.
3. **First-close readiness simulation** — close-task ownership, dependencies, evidence, period
   controls, and exception aging.
4. **Full migration audit packet** — signed source manifests, import totals, mapping decisions,
   reconciliation evidence, exception disposition, and exportable review package.
5. **Production controls** — identity provider, role and entity authorization, encrypted object
   storage, secrets management, rate limiting, backup/restore, and operational monitoring.

None of these modules may be presented as working until its behavior, tests, documentation, and
executed proof exist.
